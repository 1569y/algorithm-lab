观察重点

  • self 让四个方法访问同一份对象数据：它们共享普通栈与最小值栈。
  • 普通栈 stack 保存全部元素。
  • min_stack 只保存历史最小值，所以通常更短，不一定与 stack 等长。
  • 判断用 value <= self.min_stack[-1]：相同的最小值也要重复入栈，否则弹出最小值后无法恢复。
  • pop 弹出元素后，如果它正好等于 min_stack 栈顶，min_stack 也要同步弹出。
  • getMin 只读 min_stack 栈顶，不需要遍历普通栈，所以是 O(1)。

复杂度

  • 时间：O(1)。push、pop、top、getMin 都只操作栈顶，不需要遍历。
  • 空间：O(n)。普通栈保存全部元素；辅助的最小值栈最坏情况下也需要 O(n) 空间（元素单调不增时）。
