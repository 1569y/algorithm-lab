观察重点

  • 数字 Token 先被 int(char) 转成整数，再压入栈中等待参与运算。
  • 负数 Token 与减号运算符不同："-12" 是数字，"-" 是运算符，判断依据是 char.lstrip("-").isdigit()。
  • 遇到运算符时，栈顶连续弹出两个数字：先弹出的是右操作数 num1，后弹出的是左操作数 num2。
  • 减法写作 num2 - num1，除法写作 num2 / num1 —— 顺序写反结果就错了。
  • 除法用 int(num2 / num1) 向零截断：-7 / 2 得到 −3，而不是 −4。
  • 运算结果重新入栈，成为后续 Token 的操作数；遍历结束时栈中只剩一个值，它就是答案。

复杂度

  • 时间：O(n)。每个 Token 只处理一次；数字入栈、运算符连续弹两次再入栈，都是 O(1) 操作。
  • 空间：O(n)。合法表达式可能连续出现多个数字 Token，暂时将它们全部保存在栈中，因此最坏空间复杂度为 O(n)。
