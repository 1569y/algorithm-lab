观察重点

  • 先排序：让相同的数字聚在一起，之后才能用双指针并正确去重。
  • 固定一个数，再用左右双指针在它右边寻找另外两个数。
  • 三数之和小于 0 时右移左指针，大于 0 时左移右指针，等于 0 时记录答案。
  • 找到答案后左右指针都要移动，并跳过与刚用过的值相同的数字，避免产生重复三元组。
  • 这里展示的是基础 O(n²) 解法，剪枝属于可选优化。

复杂度

  • 时间：O(n²)。排序为 O(n log n)，外层枚举与双指针搜索合计最坏 O(n²)。
  • 空间：O(n)。nums.sort() 使用 Python 的 Timsort，最坏情况需要 O(n) 的辅助空间；双指针本身只使用 O(1) 额外变量；返回的三元组列表另计。
